# Maison Form — Premium 3D Clothing Store

A single-page clothing-store experience designed around a four-level architectural house and a considered apparel edit.

## Run locally

Open `index.html` in a modern browser. Editorial photography and fonts load from external CDNs, so an internet connection is needed for those assets.

## Included

- Responsive storefront with a perspective-based house scene, double-height ground floor, U-shaped stairs with an intermediate landing, and lift
- 21 demonstration products across seven categories, with audience, occasion, fit, price, and name filters
- Smart Find, search, product detail and sizing dialogs, wishlist, and a cart saved in browser storage
- Checkout preview with shipping calculation; no order or personal information is sent or stored

## Before a live store launch

The catalogue uses editorial image references, not verified product photography. It needs approved product assets and variant-specific images before colour variants or the requested 100–150 items per category can be published. MongoDB Atlas, payment processing, and fulfilment are not connected; checkout is a demo only.
